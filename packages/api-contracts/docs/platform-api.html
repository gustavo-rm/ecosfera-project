ECOSFERA platform-api v1.0.0

API da plataforma educacional ECOSFERA (identidade, educação, avaliação em modo leitura e gateway de simulação/tutor). Erros em RFC 7807 com traceId. A extensão x-authorization descreve, por operação, papéis, regra de posse e consentimento exigidos. WebSocket: GET /planets/{id}/stream (subprotocolos "ecosfera.v1" e "bearer.<jwt>"), mensagens {type: delta|event|tutor|alert, payload, tickId}.

Base: /platform/api/v1. Gerado do código; a fonte é packages/api-contracts/openapi/platform-api.v1.yaml.
